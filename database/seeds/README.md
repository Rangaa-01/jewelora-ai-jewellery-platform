# Development seed data

`catalogue.json` describes a sample catalogue (categories, collections, stores and
products) used **only for development and automated tests**. It is generated by
`scripts/build_seed_catalogue.py` (modern pieces) plus `heritage.json` (a few antique
pieces). Products reference real, freely licensed photographs in `photos/` (see
`photos/ATTRIBUTION.md`); the seeder uploads them and derives try-on cut-outs
automatically. A photo entry is a file name, or an object with `file` and cut-out options:
`crop` (fractions `[x0, y0, x1, y1]`, also applied to the catalogue photo), `rotate`
(90/180/270), `single_piece` (keep only the largest piece) and `punch_holes` (re-open the
inside of rings and loops the matting filled with backdrop; automatic on dark backdrops).
Products without `photos` fall back to procedurally drawn assets from `scripts/dev_assets`
(cached in `.generated/`, gitignored). `make seed` is idempotent;
`python -m app.cli seed --prune` also removes products missing from the file.

Production data is entered through the admin dashboard or imported with the shop's own
assets. Nothing in this folder is referenced by application code outside `app/cli.py`.
